## Projeto em destaque

### Brazilian E-Commerce Analytics — Olist

Projeto de análise do comércio eletrônico brasileiro utilizando Python e o dataset público da Olist.

O projeto investiga:

- Faturamento e desempenho comercial;
- Receita por categoria, estado e método de pagamento;
- Desempenho das entregas;
- Atrasos e avaliações dos clientes;
- Comportamento de recompra;
- Retenção de clientes;
- Concentração de receita por meio da análise de Pareto.
